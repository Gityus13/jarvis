START IN MINUTES

Install.
Speak. Build.

01

Install Ollama

Bring the local language model that powers JARVIS.

brew install ollama
02

Launch JARVIS

Use the macOS DMG or run the source locally. The setup script installs dependencies, creates your environment configuration, checks Ollama, and offers to download a model.

git clone https://github.com/Gityus13/jarvis.git cd jarvis chmod +x setup.sh ./setup.sh npm start
03

Customize your assistant

Before launching, edit .example.env to customize your assistant's name, Ollama model, and other configuration settings. The setup script copies this file to .env, so configure it before running setup.

nano .example.env
